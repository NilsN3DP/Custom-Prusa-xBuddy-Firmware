# N3DP Custom xBuddy Firmware v6.5.7

This package contains the updated Prusa CORE One custom firmware build based on upstream `Prusa-Firmware-Buddy` tag `v6.5.7`.

## Firmware

- `N3DP_CUSTOM_XBUDDY_FW_V6_5_7_COREONE_NOBOOT.BBF`

## Target

- Printer: `Prusa CORE One`
- Upstream basis: `v6.5.7`
- Build preset: `coreone_release_noboot`
- Build version reported by CMake: `6.5.7+57`

## Included Custom Scope

- N3DP custom firmware release documentation
- custom UI/theme color changes from the CFW branch
- CORE One autofeeder support hook
- custom `M8600` G-code stub
- previous Home Assistant light control example kept in the repository release set

## Notes

This is an independent community firmware build. It is not an official Prusa release.

Keep `LICENSE.md`, `NOTICE.txt`, and `SHA256SUMS.txt` with the firmware when distributing this package.
