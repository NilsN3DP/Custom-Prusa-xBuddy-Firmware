# Release Notes

## Release

- Name: `N3DP Custom xBuddy Firmware v55`
- Target: `Prusa CORE One`
- Variant: `lang-other`
- Firmware file: `PRUSA_BUDDY_THEME_V55_WIPER_TEMP_LANG_OTHER_CORE_ONE.BBF`

## Intended Scope

This release is a clean public release candidate built around the `v55` artifact line, before the later `v56` experimental CFW menu changes.

## Included Feature Set

- custom UI theme base with preset support
- `TriForce One` theme preset
- accent and UI polish improvements accumulated up to the `v55` line
- top vent handling for original, modified N3DP, and custom workflows
- vent open / close calibration workflow
- safe Y vent travel behavior
- nozzle cleaning profile support
- printed nozzle wiper support
- nozzle clean test entry
- Home Assistant / PrusaLink light control endpoint
- separated light targets for display, bed, and chamber
- `lang-other` language build variant
- nozzle wiper temperature handling included in the `v55` line

## Explicitly Not Included

- later `v56` CFW menu experiment
- later MK4S enclosure control work
- later fan control additions beyond the `v55` basis

## Recommended Release Title

```text
N3DP Custom xBuddy Firmware v55 for Prusa CORE One
```
