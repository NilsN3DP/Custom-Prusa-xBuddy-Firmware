# Public Release Checklist

- Verify the firmware binary is the intended `v55` artifact.
- Publish the corresponding source repository or source archive alongside the binary.
- Keep `LICENSE.md`, `NOTICE.txt`, and `SOURCE_AND_LICENSE.md` with the release.
- Do not present the release as official Prusa firmware.
- Mention that this package is prepared from the `v55` artifact line.
- Recompute checksums if any file in this folder changes.
