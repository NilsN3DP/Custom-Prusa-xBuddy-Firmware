# GitHub Release Body

```text
Independent community firmware release for the Prusa CORE One, based on Prusa-Firmware-Buddy.

This v55 release includes the custom UI theme work, TriForce One preset support,
vent calibration features, printed nozzle wiper support, nozzle cleaning options,
and Home Assistant light control.

Release package contents:
- firmware binary
- license bundle
- notice file
- source and license guidance
- release notes
- Home Assistant example YAML

This is not an official Prusa release.
Firmware code remains subject to GPL-3.0 obligations.
Non-code assets may be subject to additional license terms documented by upstream.
```
